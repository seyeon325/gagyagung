# 가갸궁 — 잊힌 말을 깨우는 여행

충남 우리말 가꿈이 4모둠 「지역사회 국어 활성화」 프로젝트의 2D 픽셀 RPG.
설치·회원가입 없이 PC·모바일 브라우저에서 실행됩니다.

**▶ 플레이하기: https://seyeon325.github.io/gagyagung/**

`main` 브랜치에 올리면 GitHub Pages가 1~2분 안에 자동으로 다시 배포합니다.

## 실행

- **가장 간단히**: `index.html` 을 브라우저로 엽니다. (서버 없이 `file://` 로도 동작)
- **로컬 서버**: `node serve.js` → http://localhost:8080
- **휴대폰 실기기 테스트**: `node serve.js --lan` 을 실행하면 같은 와이파이에서 접속할 주소(예: `http://192.168.0.12:8080`)가 표시됩니다. 휴대폰 브라우저에 그 주소를 입력하세요. Windows 방화벽이 허용 여부를 물으면 ‘개인 네트워크’만 허용하고, 테스트가 끝나면 서버를 꺼 주세요.
- **공개 배포**: 폴더 전체를 GitHub Pages · Netlify 등 정적 호스팅에 올리면 됩니다. 빌드 과정 없음.

### 실기기 점검표
- [ ] 시작 버튼 → 인트로 → 플레이까지 막힘 없음, 소리가 나는지
- [ ] 화면 끌기 이동 · 사람/바구니/서찰함을 톡 눌러 다가가기
- [ ] 오른쪽 아래 버튼 이름이 대상에 따라 ‘말 걸기 / 집기 / 살펴보기’로 바뀌는지
- [ ] 대화창 글씨 크기, 선택지 버튼을 정확히 누를 수 있는지 (대화창 빈 곳을 눌러도 선택지가 골라지지 않아야 함)
- [ ] 서찰 낱말 누르기, 수호증 이름 입력(키보드가 화면을 가리지 않는지), 저장/공유
- [ ] 가로·세로 화면 전환, 처음부터 다시 하기

## 기술 선택과 이유

지시서는 Phaser 3 를 추천했지만, 이 프로젝트는 **순수 HTML/CSS/JavaScript + Canvas 2D** 로 만들었습니다.

| | Phaser 3 | 현재 구조 |
|---|---|---|
| 용량 | 엔진만 약 1MB | 게임 전체 약 160KB(주석 포함), 외부 라이브러리 0 |
| 그래픽 | 이미지 파일 로딩 → 로컬 서버 필요 | 픽셀아트를 코드로 생성 → `index.html` 바로 실행 |
| 에셋 저작권 | 외부 에셋 출처 관리 필요 | 그래픽·사운드 모두 직접 생성 (외부 에셋 없음) |
| 한글 텍스트 | 캔버스 글꼴 렌더링 | 대화·HUD는 HTML → 선명하고 접근성 좋음 |

맵 한 장, 3~5분 분량의 게임에는 물리 엔진이나 씬 매니저가 필요 없고, 가벼움·빠른 로딩·오프라인 실행이 더 중요하다고 판단했습니다.
모듈은 `<script>` 순서로 불러오는 고전 방식이라 `file://` 에서도 막히지 않습니다.

## 대사 고치기 (예시)

`data/npcs.js` 에서 NPC마다 `talk` 배열의 **위에서부터 조건이 맞는 첫 대사**가 나옵니다.

```js
{ when: { mission: { market: 'available' } }, script: [
  '어서 와요.',                                   // NPC 대사
  { who: 'player', text: '도와드릴게요!' },        // 플레이어 대사
  { narr: '상인이 웃는다.' },                       // 해설
  { do: 'startMission', id: 'market' }             // 상태 변경
]}
```

`[[말]]` 은 금색 강조, `\n` 은 줄바꿈입니다.

| 음용수 → **마실 물** | 미션 03 안내판 | 서울시 국어바르게쓰기위원회 순화어 목록(2015.4.10.) ‘음용수→마실 물, 먹는 물’ · ✅ |

| 우측 → 오른쪽, 소재 → 있음 | 미션 03 안내판 | 표준국어대사전 「우측」 ‘=오른쪽’, 「소재(所在)」 ‘어떤 곳에 있음’ · ✅ (순화어 목록이 아니라 사전 뜻풀이로 뜻이 같음을 확인) |
| 가갸날(1926) → 한글날(1928), 2026년 100주년 | 엔딩 | 문화체육관광부 보도자료(2026) · ✅ 확인 |

- 우리말샘은 두 장터 낱말을 ‘충청’ 등 **여러 지역**의 방언으로 싣고 있습니다. 그래서 게임 속에서도 ‘충남에서만 쓰는 말’이 아니라 ‘충청을 비롯한 여러 고장의 말’로 소개합니다. 더 충남다운 낱말로 바꾸고 싶으면 `data/dialect.js` 의 출처 칸까지 함께 바꿔 주세요.
- 지역어를 틀린 말이나 우스운 말로 다루지 않습니다. 상인은 ‘동네 밥상과 살림 이야기가 담긴 말’로 설명합니다.
- 오답 피드백은 사실과 다른 설명이 끼어들지 않도록 짧고 일반적으로 썼습니다.
- 오답 보기는 사전에서 뜻이 분명히 다른 말만 씁니다. 처음엔 ‘음료수’를 오답으로 두었지만, 표준국어대사전이 ‘음용수’의 비슷한말(≒)로 ‘음료수’를 싣고 있어 ‘씻는 물’, ‘빗물’로 바꿨습니다.

## 미션 구성

| 미션 | 하는 일 | 상호작용 방식 |
|---|---|---|
| 01 충남 말 장터 | 상인이 ‘불초’(충남 말), ‘무수’로 채소를 부탁 → 단서(“전 부칠 때 넣는 가늘고 긴 초록 잎”)로 뜻을 짐작 → 장터 바구니 5개 중 골라 들고 가 전달 | 찾아다니며 **물건 집기·전달** (틀리면 다시 단서) |
| 02 말길 서찰방 | 서찰을 받아 읽기(낱말을 누르면 뜻풀이) → ‘동녘 못가 초가집’을 찾아 마을 서찰함 4곳 중 하나에 직접 넣기 → 받은 할아버지가 ‘모레 해거름’을 풀어 말하며 반응 | **읽고 해석해서 이동·배달** |
| 03 쉬운 말 안내소 | 할머니와 어려운 말 3개를 쉬운 말로 고르기(틀리면 다시) → 안내판을 직접 바꿔 달기 → 새 문장이 월드 위에 표시되고 할머니가 오른쪽 우물로 걸어감 | **고르기 → 바꿔 달기 → 결과를 눈으로 확인** |

세 미션은 순서 없이 할 수 있고, 모두 마친 뒤 궁궐의 말빛 등을 살펴보면 엔딩이 시작됩니다.
엔딩: 궁궐 복원 → 복원된 마을을 둘러보는 카메라 연출(자막) → 엔딩 화면(배운 말 정리 · 한글날 100주년 · 디지털 수호증 저장 · 다시 하기 · 계속 둘러보기).

## 개발 단계

### ✅ 1단계 — 플레이 가능한 기반 (완료)
- 시작 화면(로고·부제·픽셀 궁궐 배경·시작 버튼·조작 안내), 짧은 인트로(건너뛰기 가능)
- 46×36 타일 마을 한 장: 궁궐(정전·궁궐 문·말빛 등), 마을 마당, 장터, 서찰방, 안내소, 연못, 민가 4채와 서찰함
- 이동: WASD·방향키 · 마우스 클릭/터치 시 길찾기 이동 · 화면 끌기(가상 조이스틱), 4방향 걷기 애니메이션
- 충돌: 8px 단위, 모서리 미끄러짐, 건물 뒤에 가려지면 반투명 실루엣
- NPC 8명(대사 상태 분기), 사물 살펴보기 14곳, 상호작용 아이콘, 미션 NPC 머리 위 `!` 표시
- 대화창: 타자 효과·초상화·선택지 지원·해설/플레이어 대사 구분
- HUD 목표 패널(항상 표시), 장소 이름 배너, 알림, 사운드 켜기/끄기, 메뉴(다시 시작·조작 방법)
- 월드 변화 시스템: 채도 낮은 마을 → 구역별로 색이 물결처럼 번지며 복원, 한지 등불 점등과 말빛 알갱이, 모두 완료 시 궁궐 복원

### ✅ 2단계 — 미션·엔딩 (완료)
- 미션 3개 (위 표), 미션별 세부 단계 안내가 HUD 목표 문구에 바로 표시
- 들고 있는 물건 칸(서찰은 눌러서 다시 읽기), 머리 위 물건 표시, 지금 해야 할 일 근처 사물 반짝임
- 서찰 읽기 창, 안내판 교체와 월드 위 글씨, NPC 연출 이동
- 엔딩 연출과 디지털 수호증(이름 입력 → PNG 저장, 모바일은 공유/길게 눌러 저장), 처음부터 다시 하기
- `data/config.js` 의 `stage` 를 2로 올려 개발용 안내 문구를 끔

### ✅ 3단계 — 완성도 (완료)
- **생동감**: 주민 감정 말풍선(하트·음표·땀방울·놀람), 서 있을 때 숨쉬는 움직임과 말할 때 들썩임, 말빛이 돌아온 구역에 나비와 주민 콧노래, 연못 물비늘, 발소리
- **길 찾기 도움**: 화면 밖에 있는 `!` 주민과 말빛 등을 가장자리 화살표로 표시
- **모바일**: 행동 버튼 이름이 ‘말 걸기 / 집기 / 살펴보기’로 바뀜, 물건을 집거나 미션을 마치면 짧은 진동(소리를 끄면 함께 꺼짐), 길게 눌러도 메뉴가 뜨지 않음
- **대화**: PC에서는 선택지에 번호(1·2·3 키로 바로 선택)와 E 표시, 연타로 대사를 건너뛰지 않도록 짧은 대기
- **전환**: 시작·다시 하기에 페이드, 불러오는 동안 안내 문구, 등불 모양 파비콘
- **오류 수정**: 모바일에서 대화창 빈 곳을 누르면 첫 번째 선택지가 골라지던 문제 / 연출로 걸어온 주민과 겹치면 플레이어가 움직이지 못하던 문제
- **내용 검증**: 쉬운 말 출처를 모두 확인하고, ‘음용수’의 오답 보기에서 사전상 비슷한말인 ‘음료수’를 뺌
- `node serve.js --lan` 으로 휴대폰 실기기 테스트

### ✅ 2차 디벨롭 — 체험 행사 준비 (2026-11)
- **첫 1분**: 인트로 4장 → 2장. 시작 지점 바로 앞 가온과 첫 대화를 나누면 주변 등불 4개에 말빛이 켜지는 작은 성공 경험
- **대사**: 미션 대사를 한 번에 2~4줄로 정리 (장터 시작 9줄 → 5줄 등), 마지막 줄에 다음 할 일
- **목표 표시**: HUD에 진행 중 미션 이름과 단계(예: ‘미션 01 충남 말 장터 1/2단계’), 미션 칸을 누르면 목표 전환·찾아갈 곳 안내, 상호작용 대상 발밑에 금빛 고리
- **충남 지역성**: 장터 첫 낱말을 우리말샘에 ‘충남’으로만 실린 ‘불초’로 교체, ‘워디’ 추가, ‘부추’의 지역별 이름 비교, 엔딩에 ‘충남 말 노트’(사용 지역 표시)
- **주민 변화**: 장터 미션 뒤 손님 두리가 가게 앞으로, 서찰 미션 뒤 연못가 할아버지가 느티나무 평상으로 이동
- **저장·행사 모드**: 이어하기, `?event=1` 공용 기기 모드, 설문 버튼(주소 설정 시)
- **모바일**: 미션 칸 줄바꿈 수정, 가로 화면에서 HUD·대화창 축소와 선택지 가로 배치

### ✅ 최종 디벨롭 (2026-11-21)
- **행사 운영 오류 수정**: 행사 모드 초기화가 같은 기기의 개인 저장까지 지우던 문제, 다음 체험자 수호증에 이전 이름이 남던 문제, 초기화 전 안내 없이 바로 처음으로 가던 문제(→ 20초 안내 + 계속하기)
- **첫 화면**: 시작 화면에 한 줄 목표, PC는 말풍선 옆 [E] 키 표시
- **미션 피드백**: 미션 완료 시 화면 가운데 ‘미션 0N 완료’ 배너
- **공공언어**: 낱말 바꾸기 두 문제 + 마지막에 ‘안내문 전체를 누구나 알 수 있는 문장으로’ 고르기. 새 안내판: ‘물을 마실 수 있는 곳은 오른쪽에 있어요.’
- **엔딩**: 둘러보기 연출 건너뛰기, ‘내가 한 일’ 세 줄 → 핵심 메시지
- **모바일**: 좁은 화면에서 완료 배너가 절반 폭으로 줄던 문제 수정
